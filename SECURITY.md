# Security policy

pgtijori runs as root on database servers and holds storage and email credentials, so we
take security reports seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately via GitHub:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and which version you tested. We'll acknowledge
the report, keep you updated, and credit you in the release notes if you'd like.

## Supported versions

Only the latest release receives security fixes.
