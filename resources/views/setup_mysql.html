MySQL

liops backs up every database on this MySQL server: XtraBackup full and differential backups, binlogs shipped every few minutes, and a nightly dump of each database.

This server's folder in the bucket. Use a new name for every server, including a replacement for a lost one. It can't be changed later. Keep it with your storage credentials: restores need it.
Shown in emails.
liops logs in as MySQL's root once, to create its own MySQL account (liops@localhost, its password in {{.Data.Cfg.MySQL.DefaultsFile}}). On Ubuntu's own MySQL, root logs in without a password through the socket: leave this empty. The password is never stored.
