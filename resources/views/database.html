Restore by hand

liops never changes a database itself. Over SSH on this server, these commands restore the newest dump into a new database next to the original, so you can check it first. For an older dump, use its key from the table above. To swap it in place of the original, follow docs/restore.md §1.

sudo liops dumps url {{shq $newest.Key}}    # prints a link, valid 10 minutes
curl -fsSL -o /tmp/liops-restore.dump '<the link>'
sudo chown postgres: /tmp/liops-restore.dump
sudo -u postgres createdb {{shq (printf "%s_restored" $.Data.Row.Name)}}
sudo -u postgres pg_restore --exit-on-error -d {{shq (printf "%s_restored" $.Data.Row.Name)}} /tmp/liops-restore.dump
{{end}}{{end}} {{end}}{{end}}
